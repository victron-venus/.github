# Ownership and licensing review

The repository currently has no root `LICENSE` file. Statements about licenses of other organization projects do not establish this website's license. No OpenSSF open-source licensing criterion is claimed for this repository yet.

Before publishing a license, the owner should review the history and provenance of the HTML, JavaScript, CSS, SVG/images, profile text and imported documentation. Record original authors and existing third-party notices, including any Victron names or marks that cannot be relicensed by this project. Vendored CI tooling must retain its upstream notices.

A concrete proposal for owner review is MIT for original application source and original documentation, with a root `LICENSE` naming the actual copyright holders and a separate third-party notices file for imported material. The proposal is not a license grant. Obtain permission or replace material where provenance is unclear; do not infer ownership from repository administration rights. After that review, publish the approved license and point README/package metadata to it.
