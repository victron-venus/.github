# Victron Venus Organization

Welcome to the Victron Venus organization on GitHub. We develop open-source tools for Victron Energy systems and Venus OS.

## About

This organization hosts projects focused on:

- **Energy Management**: Grid-zero feed-in control, battery monitoring, and power optimization
- **Monitoring & Dashboards**: Real-time web dashboards, MQTT integration, and visualization tools
- **Hardware Integration**: D-Bus bridges, Bluetooth proxies, and sensor interfaces
- **Home Automation**: Home Assistant integration and automation

## Projects

### Core Projects

- [inverter-control](https://github.com/victron-venus/inverter-control) - Grid-zero feed-in control with Home Assistant integration
- [dbus-mqtt-battery](https://github.com/victron-venus/dbus-mqtt-battery) - MQTT to D-Bus bridge for JBD BMS batteries
- [inverter-desktop](https://github.com/victron-venus/inverter-desktop) - Web dashboard for inverter control

### Monitoring & Visualization

- [inverter-dashboard](https://github.com/victron-venus/inverter-dashboard) - Real-time web dashboard (Python/FastAPI)
- [inverter-dashboard-go](https://github.com/victron-venus/inverter-dashboard-go) - Real-time web dashboard (Go)
- [inverter-monitoring](https://github.com/victron-venus/inverter-monitoring) - Telegraf + InfluxDB + Grafana stack

### Hardware Integration

- [esphome-jbd-bms-mqtt](https://github.com/victron-venus/esphome-jbd-bms-mqtt) - ESPHome Bluetooth proxy for JBD BMS
- [dbus-tasmota-pv](https://github.com/victron-venus/dbus-tasmota-pv) - Tasmota power meter to D-Bus bridge
