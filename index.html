Flagship

Six projects that carry the system

Each one runs in production on a real installation. The other twenty-five build around them.

inverter-control↗

Grid-zero feed-in control for Victron inverters. Watches Home Assistant power data, drives the ESS over D-Bus, ships with its own web dashboard.

Pythonessgrid-zeroorg

dbus-mqtt-battery↗

Bridges JBD BMS batteries published over MQTT onto Venus OS D-Bus, with full DVCC support. No-BMS chains get dbus-virtual-battery.

Pythonbatterydvccorg

inverter-dashboard-go↗

Real-time web dashboard as a single Go binary that runs directly on the Cerbo. Same role as inverter-dashboard, zero Docker.

Goreal-timewebsocketorg

solar-forecast-langgraph↗

LangGraph workflow that forecasts generation from OpenMeteo weather plus historical inverter data, and pre-charges before cloudy periods.

Pythonlanggraphopenmeteo4alvit

mcp-venus-os↗

MCP server exposing Venus OS over D-Bus and MQTT to AI assistants — read anything, write only through safety-constrained control.

Pythonmcpai4alvit

venus-os-ci-toolkit↗

Reusable GitHub Actions workflows behind every repo here: lint, test, coverage, govulncheck, Scorecard — pinned by commit SHA.

ciactionsorg
